---
name: guardar-version
description: Guarda una versión del proyecto con git para poder volver atrás
---
1. Si git no está inicializado, inicialízalo y comprueba que .gitignore incluye .figma-token.
2. Muéstrame en lenguaje sencillo qué ha cambiado desde la última versión guardada.
3. Haz un commit con un mensaje breve en español que describa el cambio.
4. Confírmame que se ha guardado y cómo volver a esta versión si hace falta.
